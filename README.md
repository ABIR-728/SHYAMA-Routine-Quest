# 🌑 SHYAMA Routine Quest

**My Personal Routine, Study & Discipline App**

SHYAMA Routine Quest is my personal productivity and routine-tracking app.

I built it specifically for my own daily routine, study schedule, fitness, competitive-exam preparation, tuition, focus sessions, and long-term discipline tracking.

**List Mode**

**Timeline Mode**
- Shows the complete day from:

`00:00 → 23:59`

## 🔔 Task Notifications

SHYAMA can remind me before scheduled tasks.

Available reminder intervals:

- 1 minute
- 5 minutes
- 10 minutes
- 15 minutes
- 30 minutes

Notification settings include:

- Enable/disable reminders
- Reminder interval
- Skip completed tasks
- Include one-day Today tasks
- Test notification
- Reset today's reminder state
- Browser notification permission status

> Browser notification behavior depends on browser/PWA background execution. Guaranteed OS-level scheduling would require a native scheduler or push-based system.
